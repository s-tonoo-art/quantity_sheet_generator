# 樹抽出 数量表ジェネレータ (Web版)

ブラウザ完結のD&Dツール。Python / exe / インストール不要。
**全処理はローカルのブラウザ内で完結します**。外部送信なし。

## 使い方

1. `index.html` をダブルクリック (Chrome/Edge 推奨)。
2. 上部の **「CSV3本 (＋辞書xlsx) をここにまとめてD&D」** エリアに4ファイルまとめて落とす。
   - ファイル名で自動振り分け:
     `樹プロパティ設定_アンテナ*.csv` → antenna
     `樹プロパティ設定_ケーブル*.csv` → cable
     `樹プロパティ設定_機器個別要素なし*.csv` → equipment
     `*.xlsx` → 辞書
   - 差替え・クリアは下段の各スロットで個別可能。
3. モード・桃1含める・自動追記・並び順などのオプションを調整。
4. `実行` → xlsxダウンロード & クリップボードコピーボタンが並ぶ。
   - `Step1_全データ一覧.xlsx` — 3CSV統合＋色フラグ付き
   - `Step2_集計草案.xlsx` — 辞書適用後 (未登録は黄色扱い)
   - `Step3_数量表.xlsx` — 作業シート / 4-1_工事総括数量表 (二段組)
   - `mapping_dict.xlsx` — 更新版辞書 (未登録品目が追記される)
   - `📋 コピー` ボタン: 既存Excelに直接貼り付け用のTSV

## モード

| モード | 動作 | 例 |
|---|---|---|
| 一覧モード | 機器表示名ごとに別行 | `SAMPLE-ANT-01 Asec` / `Bsec` / `Csec` (3行) |
| 集計モード | セクタ語尾を検出し統合 | `SAMPLE-ANT-01` 合計3 記事欄=`SecA,B,C` (1行) |

検出対象の語尾パターン (大文字小文字不問):

1. 共通: `<base> Asec` / `<base>_SecA` / `<base>-Sec-B` / `<base> sec.A`
2. **RFM/RRH/RRU/ANT を名称に含む場合のみ** `<base>-A` / `<base> B` / `<base>_C`  (A/B/C限定、誤爆防止)

4セクタ以上 (D,E,F...) が出てきた場合は `parseSector` の `[A-C]` を拡張してほしい。
検出できない命名には影響しない (素通し)。

## GitHub Pages でホストする

このフォルダをリポジトリ直下に置く or `docs/` にリネームすれば、
Pages 設定で `index.html` を選んで公開できる。

## 情報漏洩対策

- 機密データはリポジトリに入れない (`.gitignore` で `*_アンテナ.csv` `*_ケーブル.csv` `*_機器個別要素なし.csv` `mapping_dict.xlsx` `out/` を除外)。
- 本ツールに「サンプル辞書」「サンプルCSV」は同梱しない。
- 処理はすべて `file:` または GitHub Pages の静的HTMLで完結。サーバへの送信ポイントなし。
- CDN依存: PapaParse / SheetJS (jsDelivr)。ネットワーク遮断環境で使う場合は両者をローカル同梱推奨。

## 辞書フォーマット

### `mapping` シート

| カテゴリ | マッチキー | 表示名 | 単位 | 記事欄 | 除外フラグ | 出現回数 |
|---|---|---|---|---|---|---|
| cable | 設備=給電線 | `{model},{len}m,({conn1}/{conn2})` | 本 | | | |

マッチ順: **機器表示名 → 型式 → 設備=&lt;設備種別名称&gt;**
表示名のトークン: `{len}` `{conn1}` `{conn2}` `{model}`

### `extras` シート

CSVに無いが毎回数量表末尾に追加したい品目 (架台・HVIE等)。

| 工種 | 項目 | 単位 | 合計 | 記事欄 |
|---|---|---|---|---|

### `order` シート (任意)

出力の並び順を決める。**1列目=設備種別名称、上から優先**、リスト外は末尾。
UIの「並び順」テキストエリアから手で編集して `mapping_dict.xlsx` 更新版に保存される。

| 設備種別名称 |
|---|
| アンテナ |
| RRH |
| 給電線 |
| BBU |

## 色ルール

| 色 | 意味 | 既定 |
|---|---|---|
| 赤1 | 新設 | 集計 |
| 青1 | 撤去 | 集計 |
| 黒 | 既設 | 除外 |
| 桃1 | 他社 | 除外 (チェック解除で含める) |

## 制限

- ブラウザ側の `FileReader` 性能に依存。数万行超はやや重い。
- SheetJS の xlsx は最小限の書式のみ (色塗りは反映しない)。見た目整形は受取側で。
- CSVは UTF-8 (BOM可) 想定。Shift-JIS の場合は要エンコード変換。
