樹抽出 数量表ジェネレータ 説明書

v0.1 · ローカル処理のみ · 外部送信なし

1. クイックスタート

  1. 画面上部の大きな箱に、樹プロパティCSV3本 + 辞書 mapping_dict.xlsx をまとめてドラッグ&ドロップ。ファイル名で自動振り分け。
  2. 必要ならオプションを調整 (モード/桃1/並び順)。
  3. [実行] ボタンを押す。
  4. 右に出る ↓ 数量表_yyyymmddhhmm.xlsx をクリックでDL、📋 数量表をコピー でTSVを既存Excelテンプレに直貼り。
  5. プレビューで行操作 (除外/統合) すれば、その場でDLボタンに最新版が反映される。
1分でわかる: CSVを投げる → 実行 → xlsxとTSVが出る。辞書は学習する。

2. 入力ファイル仕様

2.1 樹プロパティCSV (3本)

種別ファイル名キーワード主要列
antenna樹プロパティ設定_アンテナ機器表示名 / 型式 / 設備種別名称 / 線色 / 設置セクタ
cable樹プロパティ設定_ケーブル機器表示名 / 型式 / 設備種別名称 / 線色 / ケーブル長 / 端子1_コネクタ種別 / 端子1_コネクタ性別 / 端子2_…
equipment樹プロパティ設定_機器個別要素なし機器表示名 / 型式 / 設備種別名称 / 線色

エンコーディングは UTF-8 (BOM可)。Shift-JIS は事前に変換が必要。CSV先頭行は補助ヘッダ (樹図ID/番号)、2行目がカラム名。スクリプトが自動でスキップする。

2.2 辞書xlsx (任意。無くても動く)

mapping_dict.xlsx ファイル名は固定ではないが、習慣としてこの名前を使う。3シート構成 (詳細は §5)。

3. 色ルール (CSVの「線色」列)

色意味既定動作
赤1新設集計対象
青1撤去集計対象
黒既設除外
桃1他社除外 (オプション 桃1も含める で集計に乗せられる)

つまり「赤・青のみ拾い、黒は無視、桃は基本無視」。これは樹図の運用慣習に整合させている。

4. モード / オプション

4.1 モード

モード動作例
集計モード (既定)セクタ語尾を検出して畳むSAMPLE-ANT-01 Asec/Bsec/Csec 3行 → 1行 (合計3 / 記事欄=SecA,B,C)
一覧モード機器表示名ごとに別行Asec/Bsec/Csec をそのまま3行で出す

プレビューは 修正有 (Sec統合) / 修正無 (一覧) のサブタブで両方を同時に確認可。

4.2 セクタ検出パターン (集計モード時)

  1. 共通: <base> Asec / <base>_SecA / <base>-Sec-B / <base> sec.A
  2. RFM/RRH/RRU/ANT を名称に含む場合のみ: <base>-A / <base> B / <base>_C (A/B/C限定、誤爆防止)
4セクタ以上 (D, E, F…) が出てきた場合は parseSector 内の [A-C] を拡張する必要がある。

4.3 並び順 (order)

テキストエリアに設備種別名称を1行ずつ書く。辞書 order シートからも自動取り込み可。リスト外は末尾。

4.4 オプション

  • 桃1 (他社) も含める: 桃1線色の品目を集計に乗せる。
  • 未登録品目を辞書に自動追記: 辞書に無い品目が出てきたら、空テンプレートで辞書末尾に push。後で「表示名」「単位」を埋めれば次回から認識される。

5. 辞書 mapping_dict.xlsx

5.1 mapping シート (本体)

列意味例
カテゴリ3種から選ぶantenna / cable / equipment
マッチキー機器表示名 or 型式 or 設備=<設備種別名称>SAMPLE-CBL-50 / 設備=給電線
表示名出力時の項目名。トークン展開可{model},{len}m,({conn1}/{conn2})
単位合計の単位本 / 台 / 個
記事欄固定文言 (任意)他社 など
除外フラグ除外 と書けば集計から外す空 or 除外
除外上限m数値を入れると、除外フラグ=除外でもケーブル長がこの値を超える行は除外せず通常項目として表示 (空欄なら長さ無条件で除外)空 or 10
出現回数実行時に自動更新される統計列(自動)

マッチ順: 機器表示名 → 型式 → 設備=<設備種別名称>。最初にヒットしたものが採用される。
表示名トークン: {len} (ケーブル長) / {conn1} {conn2} (端子コネクタ) / {model} (型式)。

5.2 extras シート (固定追加品目)

CSVに乗ってこないが毎回末尾に足したい品目 (架台・HVIE等) を書いておく。列: 工種 / 項目 / 単位 / 合計 / 記事欄。

5.3 order シート (並び順)

設備種別名称を1列目に上から優先順で書く。UIの並び順テキストエリアと相互変換される。

6. 行操作 (除外 / 統合 / D&D)

「集計プレビュー」の行操作は即座に mapping_dict.xlsx / 数量表_*.xlsx のDLリンクに反映される (再生成)。

操作方法結果
✕ 除外行末の✕をチェック機器表示名/型式に 除外フラグ=除外。プレビューは薄字+取消線、xlsxから消える。チェック解除で復活。
新規グループ作成☑で複数行選択 → 編集バーで「+ 新規グループ」+ 表示名入力 → ⚙ 統合選択行の全キーを同じ表示名にぶら下げ、合算して1行に集約。色バッジが付く。
既存グループに追加☑で行選択 → ドロップダウンで既存グループを選ぶ → ⚙ 統合選択した既存グループに合流。
D&D合流行を別の行へドラッグ&ドロップドロップ先の表示名にソース側のキーを合流 (同一カテゴリのみ可)。
グループ解除☑選択 → ⟲ 選択行をグループ解除選択行の表示名をmappingからクリア (テンプレート/未マッチ状態に戻す)。

グループに属する行は項目セルの左に色バッジが表示される (例: Radio2271(B28A))。色は表示名のハッシュで一意に決まる。

操作の反映先はstate内のmapping。↓ mapping_dict.xlsx を押してDLしないと、ファイルには残らない。次回起動時に再読み込みすれば運用継続。

7. 出力ファイル

  • 数量表_yyyymmddhhmm.xlsx: 単一シート (列: 設備種別名称 / 項目 / 工種 / 単位 / 合計 / 記事欄)。設備種別+工種の境界に空行。
  • mapping_dict.xlsx: 未登録品目が自動追記された更新版 (autoLearn有効時)、および行操作の結果が反映された辞書。
  • 📋 数量表をコピー: 既存Excelテンプレに貼り付け用のTSV。

8. 運用フロー (学習の回し方)

  1. 初回: mapping_dict.xlsx 無しで実行 → 全行が「未登録」黄色で出力。
  2. プレビューで行操作 (除外/統合)、または「未登録一覧」タブで黄色行を見ながら、辞書に手で書き込む。
  3. 更新後の mapping_dict.xlsx をDLして保存。
  4. 次回からは同じ辞書をD&Dすれば、同じ品目は自動整形される。
  5. 辞書は 支店内共有推奨。属人化を防ぐ。

9. FAQ

辞書なしでも動く?
動く。全品目「未登録」になるだけ。実用にするなら辞書は必要。
ファイル名に「アンテナ」「ケーブル」「機器」が無いCSVは?
各スロットに手動でD&D or 参照ボタンで指定できる。バルク投下した場合は「種別不明」で弾かれる (ログ確認)。
4セクタ以上 (D, E, F…) はどうする?
現状の正規表現は [A-C] 限定。parseSector 関数を拡張する必要がある (誤検出回避の意図的制限)。
桃1 (他社) を集計に乗せたい
上部オプションの 桃1 (他社) も含める にチェック。
同じ設備種別名称内の複数行をひとつにまとめて合算したい (例: Radio2271(B8B)とRadio2271(B28A))
2行を ☑選択 → 表示名 Radio2271(B28A) 入力 → ⚙ 統合。あるいは片方の行をもう片方にD&D。
テンプレート表示名 ({model},{len}m) を使うと合算されない
意図的。長さが違うと別行になる。完全固定の文字列表示名で登録すれば全部合算される。
未登録品目を辞書に自動追記したくない
オプションの 未登録品目を辞書に自動追記 のチェックを外す。
処理がブラウザ内で完結しているか確かめたい
ブラウザの開発者ツール → Network タブを開いて実行 → CDN (jsdelivr) 以外への通信が無いことを確認。
完全オフラインで使いたい
PapaParse と SheetJS をローカルに置いて <script src=> を書き換える。
セル装飾 (色塗り) も欲しい
SheetJS 0.18.5 (CDN版) は最小書式のみ。色塗りは出力後にExcel側で。

10. トラブルシューティング

実行ボタンが押せない

CSVが1本も読み込まれていない。少なくとも1つのCSVスロットにファイルを入れる。

「未登録一覧」が大量に黄色

辞書が空 or その現場で初めて出る品目が多い。辞書未指定で動かしたか、辞書の マッチキー が機器表示名/型式と一致していない。CSVのキー文字列をそのままコピペする。

除外チェックが効かない / 反応が鈍い

ブラウザのキャッシュ。Ctrl+F5でハードリロード。それでも直らない場合はコンソール (F12) のエラーを確認。

D&Dで合流できない

カテゴリ不一致。アンテナ・ケーブル・機器は混合不可。ログに D&D: カテゴリ不一致 が出る。

「数量表をコピー」が空

クリップボードAPIの権限。HTTPS or file:// 経由でなくHTTP経由だとブロックされることがある。
また、ブラウザの設定でクリップボード許可を求められた場合は許可する。

Shift-JIS のCSVを読ませたら文字化け

CSVをUTF-8 (BOM可) に変換してから投入。Excelで「名前を付けて保存 → UTF-8 CSV」が手早い。

古い辞書を使ったら品目名が違う

辞書 mapping シートの 表示名 を更新。古いキャッシュが残るブラウザは Ctrl+F5。

11. 制限事項

  • 処理は FileReader 性能依存。数万行超でやや重い。
  • SheetJS (CDN版) のxlsx書式は最小限。色塗り・条件付き書式は反映されない。
  • CSVは UTF-8 想定 (BOM可)。Shift-JIS は要変換。
  • セクタ検出は A/B/C 限定。D以降は要コード拡張。
  • ブラウザストレージ未使用。リロードで状態消える (辞書DLで永続化)。

12. 情報漏洩対策

  • 処理はすべてブラウザ内のみ。外部送信なし。
  • CDN依存: PapaParse / SheetJS (jsdelivr.net)。完全オフライン化したい場合は両ライブラリをローカル同梱。
  • GitHub Pages 公開時は .gitignore で実データ (辞書/CSV/Step出力) を除外済み。
  • サンプル辞書・サンプルCSVは同梱しない (機器型式・局名がSB固有のため)。
  • ローカル動作確認は file:// で直接 index.html を開けばOK。
