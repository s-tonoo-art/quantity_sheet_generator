樹抽出 数量表ジェネレータ v0.1 · ローカル処理のみ

人間がCSVを読む時代は、そろそろ終わっていい。

樹プロパティCSV3本 + 辞書xlsxをD&D → 数量表.xlsx を生成。 データはブラウザ内でのみ処理され、外部送信されません。

取扱説明

ざっくり使い方

  1. 画面上部の大きな箱に、樹プロパティCSV3本 + 辞書mapping_dict.xlsxをまとめてD&D。
    ファイル名で自動振り分け: 樹プロパティ設定_アンテナ / ケーブル / 機器個別要素なし → 各スロット。.xlsx → 辞書。
  2. オプション調整 (モード/桃1/並び順)。
  3. [実行] → xlsxダウンロード + TSVコピー + プレビュー。

色ルール (CSVの「線色」列)

色意味既定
赤1新設集計
青1撤去集計
黒既設除外
桃1他社除外 (チェックで含められる)

モード

  • 集計モード (既定): セクタ語尾を検出し SAMPLE-ANT-01 ×3 / 記事欄=SecA,B,C に畳む。
  • 一覧モード: 機器表示名ごとに別行 (Asec/Bsec/Csec を保持)。

セクタ検出対象の語尾:
① 共通: Asec / SecA / Sec-B / sec.A 等
② RFM/RRH/RRU/ANT を含む名称: -A -B -C (末尾単独文字、A/B/C限定)

プレビューは「修正有 / 修正無」のサブタブで両方同時に確認可。

辞書 mapping_dict.xlsx

[mapping] シート

列例
カテゴリantenna/cable/equipment
マッチキーSAMPLE-CBL-50 / 設備=給電線
表示名{model},{len}m,({conn1}/{conn2})
単位/記事欄/除外フラグ本 / 任意 / 除外

マッチ順: 機器表示名 → 型式 → 設備=<設備種別名称>。
トークン: {len} {conn1} {conn2} {model}。

[extras] シート: CSVに無いが毎回数量表末尾に加算したい品目 (架台・HVIE等)。

[order] シート: 設備種別名称の並び順 (1列目、上から優先)。UI「並び順」テキストエリアと連動。

出力ファイル

  • 数量表_yyyymmddhhmm.xlsx: 単一シート (設備種別名称/項目/工種/単位/合計/記事欄)。設備種別+工種の境界に空行。
  • mapping_dict.xlsx: 未登録品目が追記された更新版
  • 📋ボタン: 既存Excelテンプレに直貼り用のTSVコピー

学習の回し方

  1. 画面下の「未登録一覧」タブで黄色行を確認。
  2. 辞書 mapping シートに転記 (表示名/単位/記事欄/除外フラグ)。
  3. 次回以降は黄色が消え、同じ品目は自動整形。
  4. 辞書xlsxは支店内共有推奨 (全員の知見が蓄積)。

情報漏洩対策

  • 処理はブラウザ内のみ (外部送信なし)。
  • CDN依存: PapaParse / SheetJS。完全オフライン化したい場合は両ライブラリをローカル同梱に。
  • GitHub公開時は .gitignore で辞書・CSV・Step出力を除外済。

このモーダルは Esc / 背景クリック / 右上× で閉じる。
